<Section icon={Settings} title="Recommended Divine Frequency Engine Settings">

<Section icon={Wrench} title="Performance Troubleshooting Workflow">

Early Access performance problems do not always come from the same cause. A crash may involve drivers or corrupted files, while stuttering may come from frame pacing, background overlays, or a demanding scene. Use a repeatable process instead of changing multiple variables at once.

| Symptom | First Checks | Recommended Action |
|---|---|---|
| Uneven frame pacing | Overlays, frame cap, display mode | Disable unnecessary overlays and test a stable cap |
| Low frame rate | Resolution, shadows, effects | Reduce resolution first, then lower expensive visual settings |
| Flickering image | Display mode, driver state | Switch fullscreen or borderless mode and restart |
| Controller not detected | Connection, active input device | Reconnect before launch and verify input settings |
| Crash during launch | Drivers, installation files | Update graphics drivers and verify files through Steam |
| Stutter after an update | New build, cached settings | Restart the game and retest default settings |

Use the following order when diagnosing a problem:

- Close recording tools, browser overlays, chat overlays, and unnecessary background applications.
- Confirm that graphics drivers are current.
- Verify the Divine Frequency installation through Steam.
- Restart the game after changing display mode or major graphics settings.
- Test the same area again before changing another option.
- Check the official [Steam Community hub](https://steamcommunity.com/app/2548880/) for current reports and developer responses.

The **[Divine Frequency Steam page](https://store.steampowered.com/app/2548880/Divine_Frequency/)** is the best official place to confirm the current Early Access build, supported platform, and store information. The [official Steam Discussions](https://steamcommunity.com/app/2548880/discussions/) can provide useful context, but community workarounds should be treated as temporary until supported by an official update.
