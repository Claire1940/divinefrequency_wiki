<Section icon={Wrench} title="Step-by-Step Performance Troubleshooting">

If *Divine Frequency* launches but performs poorly, treat the issue as a diagnosis process rather than changing every option at once. Early Access builds can contain temporary problems that are unrelated to the power of the PC, including shader behavior, driver conflicts, installation errors, or uneven frame pacing.

<Steps>
  <Step num="1" title="Update the Graphics Driver">
    Install the current driver for your graphics hardware, then restart Windows before testing again. Driver updates can resolve rendering problems, crashes, or unstable performance that appear after a game update.
  </Step>
  <Step num="2" title="Close Unnecessary Overlays">
    Temporarily disable recording tools, browser-heavy applications, third-party overlays, and other background software. This creates a cleaner test and helps identify whether another program is affecting frame pacing.
  </Step>
  <Step num="3" title="Verify the Steam Installation">
    Use Steam's file verification option if the game crashes, fails to launch, or displays missing assets. Let the process finish before changing graphics settings again.
  </Step>
  <Step num="4" title="Adjust One Graphics Option">
    Begin with shadows, effects, or post-processing. Test the same gameplay situation after each change so you can identify whether the problem is GPU load, resolution, or frame pacing.
  </Step>
  <Step num="5" title="Restart After Major Changes">
    Close and relaunch the game after changing display mode, resolution scaling, or several quality settings. Some changes are easier to evaluate after a clean restart.
  </Step>
</Steps>

| Symptom | First check | Next action |
|---|---|---|
| Game does not launch | Driver and file integrity | Update the driver and verify the Steam installation. |
| Stuttering during movement | Background applications and frame pacing | Close overlays and test a stable frame-rate cap. |
| Heavy drops during combat | Effects and shadows | Lower one of these settings and retest combat. |
| Flickering image | Display mode and driver | Switch between fullscreen and borderless, then restart. |
| Blurry image | Resolution scaling | Return to native resolution and adjust scaling carefully. |
| Input not detected | Active input device | Reconnect the device before launch and check settings. |

<Callout type="info" title="Early Access Troubleshooting">
Record the build version, the area where the issue appears, and the setting changes you tested. Clear notes make Steam discussions and official support channels more useful when reporting a problem.
</Callout>

Do not assume that every locked route, visual glitch, or progression issue is caused by your hardware. First determine whether the problem is reproducible after restarting, verifying files, and testing the current Steam build.

</Section>
