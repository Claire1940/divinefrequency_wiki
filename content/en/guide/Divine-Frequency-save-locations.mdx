<Section icon={FolderSearch} title="Likely Windows Save Paths to Check">

When a game does not publish its save directory, search in a controlled order. Begin with the Steam installation and userdata folders, then inspect Local, LocalLow, and Roaming AppData directories. The folder may use the game name, developer name, an internal project name, or a Steam application identifier.

Do not assume the visible game folder contains saves. Many Windows games store progress outside the installation directory so updates and reinstalls do not overwrite personal data.

| Search area | Example path | What to look for |
|---|---|---|
| Steam userdata | `C:\Program Files (x86)\Steam\userdata\` | Numeric account and app folders |
| Local AppData | `%LOCALAPPDATA%` | Folders named Divine Frequency, Abraxaes, or a project label |
| LocalLow AppData | `%USERPROFILE%\AppData\LocalLow\` | Unity-style publisher or game folders |
| Roaming AppData | `%APPDATA%` | Profile, settings, or progression files |
| Steam installation | Steam library `steamapps\common\` | Config files or clearly labeled save folders |
| Documents | `%USERPROFILE%\Documents\` | Game-created profile or backup directories |

The Steam application page uses app ID **2548880**, so a numeric directory related to that ID may be worth checking. However, the presence of a numbered folder does not prove that it contains the active save. Confirm it by comparing timestamps before and after a controlled in-game change.

<Section icon={ShieldCheck} title="How to Verify the Active Save Folder">

Finding a folder is only half the process. Early Access games can create settings, crash reports, shader caches, screenshots, and logs beside the real progression data. Verification prevents you from backing up the wrong files or restoring an outdated configuration.

Use a small, repeatable test. Avoid making major story progress solely for this purpose. If the game has a safe settings change, a new profile marker, or another low-risk action, use that change to compare timestamps.

| Verification signal | Reliability | Recommended action |
|---|---|---|
| File timestamp changes after a test session | High | Copy the folder and label it as a candidate save |
| Folder name matches the game but files never change | Low | Treat it as a settings or cache folder |
| Files are inside a numeric Steam directory | Medium | Compare timestamps and contents before trusting it |
| Folder contains logs only | Low | Do not use it as a save backup |
| Several files change together after exiting | High | Back up the complete directory |

A proper backup should preserve the whole candidate folder rather than one file selected by guesswork. Some games divide profile data, world progress, settings, and metadata into separate files. Copying only one file may produce an incomplete restore.

<Section icon={Wrench} title="Missing Saves and Troubleshooting">

A missing profile does not always mean the files are gone. The game may be reading another Windows user folder, Steam may be synchronizing a different version, or an update may have created a new directory. Work through the least destructive checks first.

| Symptom | Possible cause | First response |
|---|---|---|
| Game starts with a blank profile | Wrong folder, cloud conflict, or new save format | Check timestamps and Steam Cloud status |
| Save folder exists but progress is absent | Backup is outdated or incomplete | Compare backup dates and file groups |
| Files vanish after reinstall | Save was stored inside the install folder | Search AppData and Steam userdata |
| Game reports corrupted data | Incompatible version or damaged file | Preserve the folder and test a backup copy |
| Several folders look identical | Multiple profiles or previous installs | Use modified dates and controlled testing |

Try these non-destructive checks:

- Confirm that you launched the same Steam account used to create the progress.
- Search all user profiles on the PC if more than one Windows account is present.
- Compare the modification time of candidate files with your last play session.
- Temporarily rename a suspected folder instead of deleting it.
- Verify the game installation through Steam if files appear missing.
- Check current announcements in the [Steam Community hub](https://steamcommunity.com/app/2548880/) before assuming the save is permanently damaged.

Do not download replacement save files from random websites. Unknown files may be incompatible with the current Early Access build, may overwrite valid progress, or may contain unwanted software.

<Callout type="warning" title="Early Access Caution">
A save problem after an update may be a compatibility issue rather than a missing file. Preserve every existing copy before testing a new build or reinstalling the game.
</Callout>
