<Section icon={Save} title="Divine Frequencyのセーブ場所：確認済みの情報">

Divine Frequencyは、AbraxaesによるWindows専用のSteamアーリーアクセスホラーFPSです。利用可能な公式情報ではプラットフォームとアーリーアクセスのステータスは確認されていますが、検証済みのセーブファイルのディレクトリやファイル名のリストは公開されていません。そのため、このガイドでは**確認済みの事実**と、ローカルでの検証が必要な**考えられるWindows上の場所**を区別しています。

現在のアーリーアクセスリリースは**2026年10月26日**で、一部のUTCベースのサービスでは**2026年10月27日**と表示されます。現在のビルドは予定されている3章のうち2章をカバーしているため、開発中にセーブの動作やフォルダ構造が変わる可能性があります。

| 項目 | 現在のステータス | 実際的な意味 |
|---|---|---|
| プラットフォーム | Windows | Windowsのファイル検索とAppDataの確認を利用 |
| 配信 | Steamアーリーアクセス | Steamのuserdataとクラウド設定が関係する可能性 |
| 確認済みのセーブパス | 公開されていない | 自分のインストール環境でフォルダを検証 |
| 現在のコンテンツ | 予定3章のうち2章 | アップデートでセーブ動作が変わる可能性 |
| 公式言語 | 英語 | ファイル名やサポート情報は英語表記の可能性 |

**公式リファレンス：** [SteamのDivine Frequency](https://store.steampowered.com/app/2548880/Divine_Frequency/)で現在のストアおよびプラットフォーム情報を確認できます。[Steamコミュニティハブ](https://steamcommunity.com/app/2548880/)は、セーブ互換性に関する今後の開発者アナウンスを確認するのに最適な場所です。

<Section icon={FolderSearch} title="確認すべきWindows上のセーブパス候補">

ゲームがセーブディレクトリを公開していない場合、順序立てて検索しましょう。まずSteamのインストール先とuserdataフォルダから始め、次にLocal、LocalLow、RoamingのAppDataディレクトリを調べます。フォルダはゲーム名、開発者名、内部プロジェクト名、またはSteamのアプリケーション識別子で命名されている場合があります。

見えるゲームフォルダにセーブが含まれているとは限りません。多くのWindowsゲームは、アップデートや再インストールで個人データが上書きされないよう、インストールディレクトリの外に進行状況を保存します。

| 検索場所 | 例のパス | 探すべきもの |
|---|---|---|
| Steam userdata | `C:\Program Files (x86)\Steam\userdata\` | 数字のアカウントフォルダとアプリフォルダ |
| Local AppData | `%LOCALAPPDATA%` | Divine Frequency、Abraxaes、またはプロジェクト名のフォルダ |
| LocalLow AppData | `%USERPROFILE%\AppData\LocalLow\` | Unity形式のパブリッシャーまたはゲームフォルダ |
| Roaming AppData | `%APPDATA%` | プロファイル、設定、進行状況ファイル |
| Steamインストール先 | Steamライブラリ `steamapps\common\` | 設定ファイルや明確にラベルされたセーブフォルダ |
| ドキュメント | `%USERPROFILE%\Documents\` | ゲームが作成したプロファイルやバックアップディレクトリ |

SteamのアプリケーションページはアプリID **2548880**を使用しているため、そのIDに関連する数字のディレクトリを確認する価値があります。ただし、数字のフォルダが存在しても、アクティブなセーブが含まれている証明にはなりません。制御されたゲーム内の変更の前後でタイムスタンプを比較して確認してください。

<Steps>
  <Step num="1" title="ゲームとSteamを終了する">
    Divine Frequencyを通常どおり終了し、クリーンなファイル検索を行いたい場合はSteamも閉じます。これにより、確認中にファイルがロックされたり更新されたりするのを防げます。
  </Step>
  <Step num="2" title="主要な候補フォルダを開く">
    `%LOCALAPPDATA%`、`%APPDATA%`、`%USERPROFILE%\AppData\LocalLow\` をエクスプローラーに入力して開きます。Steamの `userdata` ディレクトリも確認してください。
  </Step>
  <Step num="3" title="名前と日付で検索する">
    `Divine Frequency`、`Abraxaes`、`2548880` を検索します。名前で結果が出ない場合は、候補フォルダを更新日で並べ替え、最後のプレイセッション中に変更されたファイルを特定しましょう。
  </Step>
  <Step num="4" title="制御されたテストを行う">
    現在のタイムスタンプを記録し、ゲームを起動して無害な設定を1つ変更するか少し進めて、終了し、どのファイルが変化したかを確認します。
  </Step>
  <Step num="5" title="編集前にコピーする">
    セーブディレクトリの候補が特定できたら、名前の変更、置き換え、削除を行う前に、フォルダ全体を別のバックアップ場所へコピーします。
  </Step>
</Steps>

<Callout type="tip" title="最速の検索方法">
ユーザープロファイルからエクスプローラーの検索を利用し、結果を**更新日時**で並べ替えましょう。テストセッション直後に更新されたファイルは、フォルダ名だけよりも有用な証拠になります。
</Callout>

<Section icon={ShieldCheck} title="アクティブなセーブフォルダの検証方法">

フォルダを見つけるのはプロセスの半分に過ぎません。アーリーアクセスゲームは、実際の進行データの他に、設定、クラッシュレポート、シェーダーキャッシュ、スクリーンショット、ログを作成することがあります。検証により、誤ったファイルのバックアップや古い設定の復元を防げます。

小さく再現可能なテストを使用してください。この目的のためだけに大きなストーリー進行をしないでください。安全な設定変更、新しいプロファイルマーカー、その他の低リスクなアクションがゲームにある場合は、その変更を使ってタイムスタンプを比較しましょう。

| 検証シグナル | 信頼性 | 推奨される対応 |
|---|---|---|
| テストセッション後にファイルのタイムスタンプが変化 | 高 | フォルダをコピーし、セーブ候補としてラベル付け |
| フォルダ名はゲームと一致するがファイルが変化しない | 低 | 設定またはキャッシュフォルダとして扱う |
| ファイルが数字のSteamディレクトリ内にある | 中 | 信頼する前にタイムスタンプと内容を比較 |
| フォルダにログのみが含まれる | 低 | セーブバックアップとして使用しない |
| 終了後に複数のファイルが一緒に変化 | 高 | ディレクトリ全体をバックアップ |

<CardGrid cols={3}>
  <Card title="セーブデータ">
    プロファイル、スロット、進行ファイル、またはプレイ後に変化する小さなバイナリファイルを探しましょう。
  </Card>
  <Card title="設定データ">
    解像度、操作、表示オプションを変更すると設定ファイルが更新される場合があります。
  </Card>
  <Card title="診断データ">
    ログやクラッシュレポートはトラブルシューティングに役立ちますが、通常はプレイヤーのセーブデータではありません。
  </Card>
</CardGrid>

適切なバックアップは、推測で選んだ1つのファイルではなく、候補フォルダ全体を保存すべきです。一部のゲームは、プロファイルデータ、ワールド進行、設定、メタデータを別々のファイルに分けています。1つのファイルだけをコピーすると、不完全な復元になる可能性があります。

<Callout type="warning" title="先に上書きしない">
現在の状態のコピーを作成する前に、疑わしい稼働中フォルダを古いバックアップで置き換えないでください。バックアップが誤りや非互換だった場合、現在の進行状況を復元するのが困難になる可能性があります。
</Callout>

</Section>

<Section icon={Save} title="バックアップと復元のワークフロー">

信頼性の高いバックアップルーティンは、アーリーアクセスリリースでは特に重要です。Divine Frequencyはまだ開発中であり、今後のアップデートでコンテンツ、進行システム、セーブ互換性が変わる可能性があります。日付付きバックアップがあれば、どのバージョンが最後に動作していたか推測せずに済む回復ポイントが得られます。

可能であれば日付とゲームバージョンを含む説明的なフォルダ名を使用してください。例：`Divine-Frequency-Save-Backup-2026-10-28`。コピーは、別のバックアップフォルダや外付けドライブなど、ゲームディレクトリの外に保管しましょう。

| バックアップのタイミング | アクション | 重要な理由 |
|---|---|---|
| アップデート前 | 候補セーブフォルダ全体をコピー | アップデート前の状態を保存 |
| トラブルシューティング前 | 現在のファイルを複製 | 安全なテストが可能に |
| 進行に成功した後 | 日付付きバックアップを作成 | 最近の復元ポイントを提供 |
| 再インストール前 | セーブと設定を別々にバックアップ | 誤った消失を防止 |
| 復元後 | 起動してプロファイルを確認 | 互換性を確認 |

<Callout type="success" title="安全な復元ルール">

Steamクラウドが有効な場合、古いローカルバックアップが新しいクラウド版と競合する可能性があります。復元後に起動する前に、ゲームのSteamプロパティとクラウド同期の状態を確認してください。Steamがどちらのバージョンを保持するか尋ねてきたら、タイムスタンプとバックアップ名を比較してから選択しましょう。

</Section>

<Section icon={Wrench} title="セーブ消失とトラブルシューティング">

プロファイルが表示されないからといって、ファイルが必ずしも失われたわけではありません。ゲームが別のWindowsユーザーフォルダを読み込んでいる、Steamが別のバージョンを同期している、またはアップデートが新しいディレクトリを作成した可能性があります。破壊的でない確認から順に行いましょう。

| 症状 | 考えられる原因 | 最初の対応 |
|---|---|---|
| ゲームが空のプロファイルで起動する | 誤ったフォルダ、クラウド競合、新しいセーブ形式 | タイムスタンプとSteamクラウドの状態を確認 |
| セーブフォルダはあるが進行状況がない | バックアップが古いまたは不完全 | バックアップ日付とファイルグループを比較 |
| 再インストール後にファイルが消える | セーブがインストールフォルダ内に保存されていた | AppDataとSteam userdataを検索 |
| ゲームがデータ破損を報告 | 互換性のないバージョンまたは破損ファイル | フォルダを保管し、バックアップコピーをテスト |
| 複数のフォルダが同一に見える | 複数のプロファイルまたは以前のインストール | 更新日と制御されたテストを使用 |

これらの非破壊的な確認を試してみてください：

- 進行状況を作成したのと同じSteamアカウントで起動したことを確認する。
- PCに複数のWindowsアカウントがある場合、すべてのユーザープロファイルを検索する。
- 候補ファイルの更新時刻と最後のプレイセッションを比較する。
- 疑わしいフォルダは削除せず、一時的に名前を変更する。
- ファイルが見つからない場合は、Steamでゲームのインストールを検証する。
- セーブが完全に破損したと決めつける前に、[Steamコミュニティハブ](https://steamcommunity.com/app/2548880/)で現在のアナウンスを確認する。

不明なウェブサイトから代替セーブファイルをダウンロードしないでください。不明なファイルは現在のアーリーアクセスビルドと互換性がない、有効な進行状況を上書きする、または望ましくないソフトウェアを含む可能性があります。

<Callout type="warning" title="アーリーアクセスの注意">
アップデート後のセーブ問題は、ファイル消失ではなく互換性の問題である場合があります。新しいビルドのテストやゲームの再インストールの前に、既存のコピーをすべて保管してください。
</Callout>
