<Section icon={Monitor} title="Divine Frequency システム要件の状況">

現在の *Divine Frequency* Early Access 版は、Abraxaes が開発・販売する Windows PC 向けのホラーFPSです。確認できる公式情報では、Steam プラットフォームと Early Access であることは確認できますが、CPU、GPU、メモリ、ストレージについて安全に転載できる完全な仕様表は提供されていません。

そのため、根拠のない最低要件や推奨ハードウェア数値に頼ることは避けてください。代わりに、以下の確認済みプラットフォーム情報を参考にし、対象のPCでゲームを段階的にテストしてください。

| 項目 | 確認済み情報 | 実際の意味 |
|---|---|---|
| プラットフォーム | Windows PC | 対応している Steam 版をプレイするには Windows システムが必要です。 |
| ストア | Steam | 公式の Steam ページからゲームをインストールして起動してください。 |
| リリース形態 | Early Access | 開発中にパフォーマンスや技術的な挙動が変わる可能性があります。 |
| 現在のコンテンツ | 予定されている3章のうち2章 | 戦闘、探索、負荷の高い屋内エリアでパフォーマンスをテストしてください。 |
| 言語 | Steam では英語を掲載 | 現在のビルドでインターフェースと対応テキストを確認してください。 |
| ハードウェア表 | 確認できる情報には未掲載 | 非公式のハードウェア推定値を公式要件として扱わないでください。 |

<Callout type="warning" title="未確認の仕様を信用しないでください">
システム要件一覧は、開発者または公式ストアページが確認した場合にのみ掲載すべきです。PCの性能が非公式の推定値に近い場合でも、ゲームが特定の動作をすると決めつけず、現在のビルドを実際にテストしてください。
</Callout>

最も確実な開始地点として、[公式 Divine Frequency Steam ページ](https://store.steampowered.com/app/2548880/Divine_Frequency/)を確認し、インストール前に最新のストア情報をチェックしてください。Early Access のプロジェクトではアップデートに伴って Steam の掲載内容が変わる可能性があるため、2026年後半のビルドでは、より詳しい技術情報が追加される場合があります。

</Section>

<Section icon={Settings} title="Early Access 向けの推奨グラフィック設定">

ゲームが完全なハードウェア対応表を公開していない場合、最も安全な設定方法は、段階的に調整することです。まずデフォルト設定から始め、実際のゲームプレイ中の挙動を確認してから、主要な設定を一度に1つだけ変更してください。

すべての設定を最初から下げる必要はありません。*Divine Frequency* は、暗い屋内、視覚効果、探索エリアを含むシュールなレトロホラー表現を採用しているため、単純なメニュー画面とはフレームペーシングの感覚が異なる場合があります。

| 設定項目 | 推奨される開始設定 | 調整の優先順位 |
|---|---|---|
| 表示モード | フルスクリーンまたはボーダーレス | ちらつきやフレームペーシングの乱れがある場合に変更します。 |
| 解像度 | モニターのネイティブ解像度 | GPUに負荷がかかっている場合はレンダリング解像度を下げます。 |
| 品質プリセット | デフォルトプリセット | 個別に変更する前の基準として使用します。 |
| シャドウ | デフォルト、必要に応じて下げる | 暗いシーンの描画負荷が高い場合に、最初に下げる候補です。 |
| エフェクト | デフォルト、必要に応じて個別に下げる | 戦闘中のエフェクトで目立ったフレーム低下が起きる場合に調整します。 |
| ポストプロセス | デフォルト、必要に応じて個別に下げる | 画面効果が視認性やパフォーマンスに影響する場合に下げます。 |
| フレームレート | PCに適した安定した目標値 | 不安定な高フレームレートより、一定の上限を設定した方が快適な場合があります。 |

  <Card title="変数を1つだけ変更する">

  </Card>
  <Card title="安定性を優先する">

  </Card>
</CardGrid>

<Callout type="tip" title="パフォーマンスのヒント">
パフォーマンスを判断する際は、タイトル画面ではなく、実際のゲームプレイを代表するエリアを使用してください。屋内エリア、戦闘、素早い移動は、Early Access ビルドをテストするうえでより有用です。
</Callout>

実際の調整手順は次のとおりです。

1. 表示モードを確認します。
2. ネイティブ解像度でテストします。
3. シャドウまたはエフェクトを個別に下げます。
4. 必要な場合のみレンダリング解像度を下げます。
5. 不要なオーバーレイやバックグラウンドアプリケーションを終了します。
6. 大きなグラフィック設定を変更した後はゲームを再起動します。

</Section>

<Section icon={Wrench} title="パフォーマンスの段階的なトラブルシューティング">

*Divine Frequency* が起動するものの動作が重い場合は、すべての設定を一度に変更するのではなく、問題を診断する手順として対応してください。Early Access ビルドでは、PCの性能とは関係なく、一時的な問題が発生する場合があります。これには、シェーダーの挙動、ドライバーの競合、インストールエラー、フレームペーシングの乱れなどが含まれます。

<Steps>
  <Step num="1" title="グラフィックドライバーを更新する">
    グラフィックハードウェア向けの最新ドライバーをインストールし、再度テストする前に Windows を再起動してください。ドライバーの更新により、ゲームのアップデート後に発生する描画の問題、クラッシュ、不安定なパフォーマンスが解消される場合があります。
  </Step>
  <Step num="2" title="不要なオーバーレイを終了する">
    録画ツール、ブラウザーを多く使用するアプリケーション、サードパーティ製オーバーレイ、その他のバックグラウンドソフトウェアを一時的に無効にしてください。これにより、よりクリーンな状態でテストでき、別のプログラムがフレームペーシングに影響しているか確認しやすくなります。
  </Step>
  <Step num="3" title="Steam のインストールを確認する">
    ゲームがクラッシュする、起動しない、または一部のアセットが表示されない場合は、Steam のファイル整合性確認機能を使用してください。再びグラフィック設定を変更する前に、処理が完了するまで待ちます。
  </Step>
  <Step num="4" title="グラフィック設定を1つだけ調整する">
    シャドウ、エフェクト、ポストプロセスから始めます。変更するたびに同じゲームプレイ状況をテストし、問題が GPU 負荷、解像度、フレームペーシングのどれに関係しているか確認してください。
  </Step>
  <Step num="5" title="大きな変更後に再起動する">
    表示モード、解像度スケーリング、複数の品質設定を変更した後は、ゲームを終了して再起動してください。変更内容によっては、クリーンな再起動後の方が評価しやすくなります。
  </Step>
</Steps>

| 症状 | 最初に確認すること | 次の対応 |
|---|---|---|
| ゲームが起動しない | ドライバーとファイルの整合性 | ドライバーを更新し、Steam のインストールを確認します。 |
| 移動中にカクつく | バックグラウンドアプリケーションとフレームペーシング | オーバーレイを終了し、安定したフレームレート上限を試します。 |
| 戦闘中に大きくフレームレートが低下する | エフェクトとシャドウ | どちらか一方を下げて、戦闘を再度テストします。 |
| 画面がちらつく | 表示モードとドライバー | フルスクリーンとボーダーレスを切り替え、その後再起動します。 |
| 画面がぼやける | 解像度スケーリング | ネイティブ解像度に戻し、スケーリングを慎重に調整します。 |
| 入力が認識されない | 使用中の入力デバイス | 起動前にデバイスを接続し直し、設定を確認します。 |

<Callout type="info" title="Early Access のトラブルシューティング">
ビルドバージョン、問題が発生するエリア、テストした設定変更を記録してください。明確なメモがあると、Steam のディスカッションや公式サポート窓口で問題を報告する際に役立ちます。
</Callout>

通行できないルート、視覚的な不具合、進行上の問題がすべてハードウェアの原因だとは考えないでください。まずは再起動、ファイルの整合性確認、現在の Steam ビルドでのテストを行い、問題が再現するか確認してください。

</Section>
