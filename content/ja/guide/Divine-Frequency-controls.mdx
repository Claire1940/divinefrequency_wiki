<Section icon={Settings} title="Divine Frequencyの操作方法：最初に設定する項目">

Divine Frequencyの操作方法は、個々のボタンを確認するのではなく、入力設定全体として調整するのが効果的です。序盤のエリアを探索する前に、移動、エイム、インタラクション、戦闘アクション、アビリティへのアクセス、メニュー操作を確認しましょう。現在このゲームはWindows向けのEarly AccessホラーFPSであるため、正確なキー割り当てや利用可能なオプションは、2026年の開発中に変更される可能性があります。

最も重要なのは一貫性です。移動は予測しやすく、メイン攻撃は簡単に入力でき、防御や緊急アクションが頻繁に使うメニュー入力と競合しないようにしましょう。一度に複数の設定を変更するのは避けてください。操作カテゴリーを1つずつ調整し、安全なエリアでテストして、快適性が向上した場合のみその設定を維持します。

| 操作エリア | 最初に確認する設定 | 重要な理由 |
|---|---|---|
| 移動 | 前進、ストレイフ、しゃがみ、ダッシュの入力 | 戦闘が始まる前に、移動が安定していることを確認できる |
| カメラ | 視点感度とエイムの反応 | 脅威をどれだけ素早く追えるかを左右する |
| 戦闘 | メイン攻撃、代替アクション、リロード、武器切り替え | 近距離での遭遇時の迷いを減らせる |
| アビリティ | サイオニックまたはユーティリティアクションの入力 | メニューを開かずに特殊ツールを使える |
| インタラクション | 使用、調査、解除、拾う操作 | 環境の手がかりや進行に必要なオブジェクトの見落としを防ぐ |
| メニュー | 一時停止、インベントリ、設定、マップへのアクセス | 遭遇の合間にリソースを管理しやすくなる |

キーボードとマウスを使う場合は、まず中程度の視点感度から始めましょう。高感度なら素早く方向転換できますが、正確なエイムや環境の確認が不安定になる可能性があります。特に狭い部屋で敵との距離感を学ぶ段階では、低めの感度のほうが操作しやすいことが多いです。

ゲームパッドを使う場合は、まずゲームが使用中のデバイスを認識していることを確認します。表示されるボタン表示を確認したら、カメラ操作、トリガーの反応、スティックのドリフト、振動、メニュー操作をテストしてください。表示が実際のデバイスと一致しない場合は、ゲームを再起動する前にコントローラーを接続し直します。

<Callout type="tip" title="編集部のヒント">
試す前にシンプルな基準設定を保存しておきましょう。安定したレイアウトがあれば、後から変更した内容がエイムを改善したのか、それとも単に感触が変わっただけなのかを判断しやすくなります。
</Callout>

<Section icon={Target} title="操作設定の手順">

Divine Frequencyの操作方法を新しく設定したり見直したりする場合は、次の順番で進めてください。移動とカメラの挙動は、その後の戦闘判断すべてに影響するため、順序が重要です。

<Steps>
  <Step num="1" title="アクティブな入力デバイスを確認する">
    設定メニューから始め、ゲームがキーボードとマウス、またはコントローラーのどちらを読み取っているか確認します。カメラを動かし、インタラクションを実行し、メニューを開いて、選択したデバイスが安定して反応することを確認してください。
  </Step>
  <Step num="2" title="感度より先に移動を設定する">
    前進、ストレイフ、後退、しゃがみ、ダッシュをテストします。指を無理な位置に置かなくても、快適に移動できることを確認してください。基本的な移動が自然に感じられる前に、エイムの最適化を始めないようにしましょう。
  </Step>
  <Step num="3" title="中程度のカメラ反応を選ぶ">
    まずは中間程度の視点感度から始めます。近くの目印に向かって方向転換し、動く脅威を追い、制御された方向転換を行ってください。方向転換が遅く感じる場合のみ感度を上げ、標的を頻繁に通り過ぎてしまう場合は下げます。
  </Step>
  <Step num="4" title="緊急アクションを手の届く位置に置く">
    回復、防御アクション、リロードなどの生存に必要な操作へすぐアクセスできるようにします。利用できるアクションはビルドによって異なる可能性があるため、別のゲーム向けに設計されたレイアウトをそのまま真似るのではなく、自分が最も頻繁に使う機能を優先してください。
  </Step>
  <Step num="5" title="安全なエリアでレイアウトをテストする">
    慣れたエリアを移動しながら、戦闘、インタラクション、メニューへのアクセス、リソース管理を確認します。入力によって誤操作や遅延が発生した場合は、そのキー割り当てだけを修正して、もう一度テストしてください。
  </Step>
</Steps>

| テスト | 合格条件 | 失敗した場合の調整 |
|---|---|---|
| カメラの方向転換 | 繰り返し行き過ぎることなく方向転換できる | 視点感度を少しずつ下げる |
| 標的の追跡 | 絶えず修正しなくてもエイムが脅威を追える | 感度とエイムの反応を見直す |
| ダッシュへのアクセス | 移動を乱さずにダッシュを発動できる | ダッシュをより使いやすい入力へ移す |
| インタラクション | ドア、オブジェクト、拾えるアイテムに確実に反応する | インタラクションのキーまたはボタンを確認する |
| 緊急アクション | プレッシャー下でも回復や防御ツールにアクセスできる | 近くにあり、他と区別しやすい入力へ割り当てる |

<Callout type="success" title="安定した設定の原則">
優れた操作レイアウトとは、基本操作を意識して探さなくても使えるものです。メニューで立ち止まっているときだけでなく、プレッシャーのかかる状況でもテストしましょう。
</Callout>

<Section icon={Swords} title="キーボード・マウス・ゲームパッドの比較">

すべてのDivine Frequencyプレイヤーにとって唯一の最適な操作方法があるわけではありません。このゲームには、遠距離戦闘、探索、リソース管理、超自然的またはサイオニックな選択肢が組み合わされています。不慣れな場所を移動しながら周囲への注意を維持できるデバイスを選びましょう。

キーボードとマウスは、直接的なカメラ操作と複数の独立した入力への素早いアクセスを重視するプレイヤーに適しています。移動、インタラクション、武器切り替え、アビリティのキーを分けて設定しやすいのも利点です。一方で、キー配置が悪いと、緊張した遭遇中に指を大きく動かす必要が生じます。

ゲームパッドは、より滑らかなアナログ移動と、カメラ操作と移動を組み合わせやすい快適さを提供します。ただし利用できるボタン数は限られているため、重要な操作が長押し、ラジアルメニュー、ボタンの組み合わせに依存する場合があります。難しい遭遇に入る前に、そうした組み合わせを確認してください。

| 入力方法 | 主な長所 | よくあるリスク | 推奨される初期アプローチ |
|---|---|---|---|
| キーボードとマウス | 正確なカメラ操作と独立したキーアクセス | 不自然なキー割り当てが緊急操作を遅らせる可能性がある | 中程度の感度を使い、戦闘キーを論理的にまとめる |
| ゲームパッド | 滑らかな移動と快適なアナログ操作 | ボタン数の制限と感度の問題が起こる可能性がある | ボタン表示、スティックの反応、トリガーの挙動を確認する |
| 混合デバイス | 好みの機能をテストするのに便利 | デバイスを切り替えると表示や挙動が変わる可能性がある | 戦闘中は1つのメインデバイスを使う |
| 初期レイアウト | 最も早く使い始められる | すべての手の位置に適しているとは限らない | まず試し、不快な操作だけを変更する |

マウスを使う場合は、極端に速い方向転換を追い求めないようにしましょう。ホラーFPSの遭遇では、遅いカメラ回転よりもパニックによる移動のほうが危険になることが多いです。制御しやすい反応なら、部屋を確認し、射線を合わせ、退路を確保しやすくなります。

ゲームパッドを使う場合は、水平方向と垂直方向の両方のカメラ操作をテストしてください。左右を見るときは快適でも、高い位置や低い位置の標的を追うときに扱いにくいレイアウトがあります。また、振動によって戦闘のフィードバックを読み取りやすくなるのか、探索中に気が散るのかも確認しましょう。

<Callout type="warning" title="入力に関する警告">
操作上の問題をゲームプレイの仕様だと決めつけないでください。入力に遅延がある、表示が一致しない、反応しないと感じる場合は、まずデバイスの認識、オーバーレイ、ドライバー、アクティブな操作プロファイルを確認しましょう。
</Callout>

<Section icon={Shield} title="操作方法、パフォーマンス、戦闘の安定性">

操作感はキー割り当てだけで決まるものではありません。表示モード、解像度、フレームペーシング、バックグラウンドアプリ、グラフィック設定によって、エイムの反応性が変わることがあります。パフォーマンスが不安定に感じられる場合は、操作レイアウト全体を作り直す前に、技術設定を調整してください。

まずは標準のグラフィックプリセットを使用し、探索または戦闘を代表するエリアでゲームをテストします。パフォーマンスが安定しない場合は、負荷の高い項目を1つずつ下げてください。解像度、影、エフェクト、ポストプロセスはテストしやすい項目ですが、すべてを同時に変更すると原因を特定しにくくなります。

| 技術設定 | 最初に推奨される確認 | 操作に影響する理由 |
|---|---|---|
| 表示モード | フルスクリーンとボーダーレスを試す | モードの切り替えがフレームペーシングに影響する可能性がある |
| 解像度 | ネイティブ解像度から始める | 描画負荷が反応性に影響しているか確認できる |
| アップスケーリング | 利用可能で必要な場合のみ有効にする | パフォーマンスは向上するが、画質が変わる可能性がある |
| 影とエフェクト | テスト中に個別に下げる | すべての映像設定を変更せずに負荷を減らせる |
| バックグラウンドアプリ | 不要なオーバーレイを閉じる | 競合や中断の可能性を減らせる |
| フレームレートの挙動 | 安定したペーシングをテストする | 一貫した動きのほうが通常は操作しやすい |

画面がちらつく、フレームペーシングが不均一に感じられる、入力に遅延がある場合は、表示モードを切り替えてゲームを再起動してください。グラフィックドライバーを最新の状態に保ち、問題が続く場合はSteamでインストールファイルの整合性を確認します。技術的な挙動がアップデートごとに変わる可能性のあるEarly Accessビルドでは、これらの確認が特に役立ちます。

現在のWindowsビルドと利用可能な技術情報については、公式の[Divine Frequency Steamページ](https://store.steampowered.com/app/2548880/Divine_Frequency/)を利用してください。[Steamコミュニティハブ](https://steamcommunity.com/app/2548880/)では、入力やパフォーマンスの問題について、現在のプレイヤー報告や議論も確認できます。

<Callout type="info" title="パフォーマンスに関する注意">
大きなグラフィック変更を行った後は、操作をテストしてください。フレームペーシングが安定しているときに快適だった感度でも、負荷の高いエリアの描画に苦戦していると、異なる感触になることがあります。
</Callout>

<Section icon={Map} title="Early Access向けの推奨操作習慣">

操作レイアウトは、現在のDivine FrequencyのEarly Accessコンテンツを生き残るための要素の一つにすぎません。良い習慣を身につけることで、緊急入力の必要性を減らし、探索中の状況把握もしやすくなります。

不慣れな部屋に入る前に退路を確認し、移動操作をすぐ使える状態にしておきましょう。方向転換、ダッシュ、オブジェクトとのインタラクション中に誤って押してしまう可能性のある操作へ、重要なアクションを割り当てるのは避けてください。レイアウトを変更した場合は、任意の遭遇に挑む前に、危険度の低いエリアを進んで感触を確認します。

| 状況 | 操作習慣 | 実際の効果 |
|---|---|---|
| 未知の部屋に入る | 移動と退避の入力をすぐ使える状態にする | キーを探さずに戦闘から離脱できる |
| 近距離で戦う | 最大感度ではなく制御された方向転換を使う | 誤った過修正を減らせる |
| 限られたリソースを管理する | メニューへのアクセスを戦闘入力と分ける | 間違ったタイミングでメニューを開く可能性を下げられる |
| 封鎖されたルートを再訪する | インタラクション操作を一貫して使う | 環境の確認を繰り返しやすくなる |
| アップデート後 | ボタン表示とキー割り当てを再確認する | 長時間のセッション前に変更を発見できる |

未解決のドア、進入できない道、任意の部屋について短いメモを残しておきましょう。この習慣は、すべての通路を何度も引き返すよりも信頼できます。後のアップデートで進行ルートが変更されたりコンテンツが追加されたりした場合も、メモがあれば新しいルートと以前は利用できなかったエリアを区別しやすくなります。

<Callout type="tip" title="探索のヒント">
目印と達成済みの目標を使ってルートを整理しましょう。一貫したナビゲーションはパニックを減らし、予想外の遭遇時にも操作レイアウトを使いやすくしてくれます。
</Callout>
